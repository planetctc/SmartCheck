smartCheck（原名 smartDisk、smartPC）版本记录 / Version history

0.19.2  2026-11-26
  - 远程服务的后台地址已经内建：客户电脑只要贴授权码、填客户名称就可以，不用再打网址。
  - 硬盘状态判断更严格：有「待映射扇区」或「无法修正扇区」、重映射扇区达到 100 个、健康度掉到 0%、
    NVMe 寿命用完，都直接标「建议更换」（红色），不再只是「需要注意」。
  - 坏道扫描找到坏道、或 SMART 自检失败的硬盘，状态也会改成「建议更换」，画面和 PDF 报告都一样。
  - 「无法修正错误」（ID 187）不是 0 时会标「需要注意」。

0.19.1  2026-11-26
  - 「硬件与温度」页和出机检测的「温度与风扇」步骤改成实时更新：温度、风扇、功耗每 2 秒刷新一次，不用再开 HWMonitor。
  - 每个温度、风扇、功耗旁边显示「最高」值（像 HWMonitor 的 Max 栏），可以按「最高值清零」重新开始记。
    跑 Prime95 或其他软件时开着这一页，就能直接看到最高温度和最高功耗。

0.19.0  2026-11-26
  - 烤机测试新增「高强度」模式（默认）：用 CPU 的 AVX2 / FMA 指令全速运算，负载接近 Prime95（Small FFT），
    CPU 会比「标准」模式热很多，更能测出散热不足和不稳定。旧 CPU 没有 AVX2 时会自动改用 AVX 或 SSE2。
  - 烤机结果和 PDF 报告会写明用了哪一种强度。
  - 内存快速测试加强：改由检测程序执行，测试的内存会锁在实体内存里（不会被 Windows 换到硬盘），测得更多（只留 1 GB 多给 Windows），
    用全部 CPU 核心跑 14 种测试：地址测试、移动反转（全 0/全 1、0x55、每个字节的走动 1）、两组随机数，和 MemTest86 的主要测试同类。
    16 GB 内存一遍约 1 到 2 分钟。

0.18.0  2026-11-26
  - 改名为 smartCheck（新 logo）。已经装了的电脑会直接更新成新名字，设置、监控记录、授权码和开机监控都保留。
  - 全新界面：左边是功能菜单（总览、出机检测、硬件与温度、烤机测试、内存测试、电池），下面是硬盘列表。
  - 新的「总览」页：一打开就看到这台电脑几项正常、哪一项有问题，每项结果点一下就跳到详细页面；
    也列出所有硬盘的评级和健康度，以及烤机、内存测试的结果。
  - 新的「出机检测」页：一步一步做完硬件资料、Windows 激活、硬盘、温度、电池、烤机、内存测试，做完一项打勾；
    「一键跑完剩下的测试」会自动接着做烤机和内存测试，做完直接跳到生成报告。
  - 皮肤选择搬到「设置」里，左下角只留「重新检测」和「检测报告」两个按钮，硬盘列表有更多位置。
  - 网上更新改从 smartCheck-releases 下载（旧网址会自动转过去）。

0.17.1  2026-11-26
  - 关掉 smartPC 窗口时，正在跑的烤机或内存测试会自动停止（以前会在背景继续满载，看不到也停不了）。
  - 烤机时背景监控不再跳「电脑温度过高」提醒（烤机本来就会让电脑变热）。
  - 烤机中途死机或断电后，就算开机时背景监控先启动，打开 smartPC 也会正确显示「测试中途停止」。
  - 烤机、内存测试、硬盘测速/扫描不能同时跑，避免互相影响结果。
  - 内存测试如果中途失败，不会再显示成「没有错误」，也不会印进报告；不会卡在「测试中」。
  - 电池报告读取时切换页面不会再显示空白。
  - PDF 报告有完整电池报告时，不再重复印一行简短的电池资料。

0.17.0  2026-11-26
  - 「本机信息」页新增「烤机测试」：让 CPU（可选加上显卡）全力跑 5/10/20/30 分钟，每 2 秒记录温度、频率、功耗和风扇，
    画出温度曲线。温度超过设置里的门槛、CPU 因为过热明显降频、或测试中途死机/重启，都会判为不通过或注意。
  - 新增「内存测试」：快速测试在 Windows 里把大部分空闲内存写满再读回检查，几分钟完成，不用重启；
    也可以一键安排 Windows 内存诊断（完整测试，需要重启），重启后结果会显示在这里。
  - 笔记本新增「电池报告」：电池损耗、充电次数、满电/设计容量、现在和新电池时的续航，还有容量变化曲线，
    可以打开 Windows 的完整电池报告。
  - 三项结果都会印进 PDF 检测报告，设置的功能表里可以各自关掉。

0.16.0  2026-11-26
  - 背景监控也会检查 CPU、显卡、主板和内存温度：连续两次检查（约 30 分钟）都超过设置里「警告门槛」的「过热」温度，
    就会跳出「电脑温度过高」提醒（同一个零件一天最多提醒一次），WhatsApp 按钮会写好是温度问题。
    以前只有硬盘会提醒，CPU 再热也只在打开 smartPC 时看得到。
  - 托盘「立即检查」也会列出目前的 CPU 和显卡温度。

0.15.1  2026-11-25
  - 修正网上更新：背景监控已经悄悄下载好更新时，按「下载并安装」会没有反应。现在会直接问你要不要重启安装；
    下载中左下角会显示「正在下载更新… xx%」，重复按也会提示正在下载。

0.15.0  2026-11-25
  - 改名为 smartPC：现在不只是检测硬盘，还有本机信息、传感器和背景监控。已经装了的电脑会直接更新成新名字，设置、监控记录、授权码和开机监控都保留。
  - 传感器改成按芯片分组、两栏排列，不用一直往下拉。
  - CPU 温度不再重复显示：CPU 自己有温度读数时，只显示 CPU 的，不再另外列出主板芯片量到的 CPU 温度。
  - 设置里新增「功能开关」：硬盘测速、坏道扫描、SMART 自检、收购评级、健康记录、容量真假检测、安全擦除、传感器、背景监控，都可以各自打开或关掉。
  - 硬盘页面重新排版：上面是健康度和重点数字，下面分「概览 / 检测工具 / 详细数据」三个分页，不用一直往下拉；健康记录图缩小，卡片样式更整齐。
  - 设置里新增「警告门槛」：健康度下降几趴提醒客户、机械硬盘/SATA 固态/NVMe 过热温度、CPU/显卡/主板的偏高和过热温度，都可以自己调，也可以一键恢复默认。

0.14.0  2026-11-25
  - 本机信息多了「传感器」：CPU 温度和功耗、显卡温度/风扇/功耗、主板风扇转速、主板电压（+12V、+5V、+3.3V、CPU 电压等）、内存温度。
    CPU 和主板的部分要先按一次「安装传感器驱动」（PawnIO，有数字签名，从官方 GitHub 下载，只装一次）；
    没装驱动也能看到显卡和主板温度区。温度偏高会提示检查散热，检测报告也会印出温度和风扇。
  - 笔记本电池多显示充电次数。
  - 修正背景监控：关掉 smartDisk 窗口后会马上缩到右下角托盘继续监控（以前要等重新开机/登入才出现）；
    第一次会弹提示告诉你它在那里。开机自动启动的排程改成用目前的 Windows 用户，确保能以管理员权限启动。

0.13.0  2026-11-25
  - 跟 smartAcc 连接：生成检测报告时可以勾选「同时存进 smartAcc」，报告 PDF 会按硬盘序列号自动存进
    smartAcc 里对应的维修单、收购单和发票附件。smartAcc 在同一台电脑上就能直接用；
    连另一台电脑上的 smartAcc 需要授权码。smartAcc 有登入账号的话，在设置 →「smartAcc 连接」填用户名和密码（密码加密保存）。
    需要 smartAcc 2.1.1 或以上。

0.12.0  2026-11-25
  - 远程通知（PLANET 专用，要授权码）：设置 →「远程服务（授权）」贴上授权码后，这台电脑会把硬盘状况传到店家的后台，
    硬盘变差、出现坏道或过热时店家会收到通知，后台网页也能看到每台客户电脑的硬盘状况。
    没有授权码就不会上传任何资料，客户还是只在自己电脑上看到提醒。

0.11.0  2026-11-25
  - 容量真假检测：把 U 盘 / 硬盘的空余空间全部写满再读回来核对，查出扩容的假容量盘。不会动原有文件，测完自动删掉测试文件。
  - 安全擦除：卖盘或送人前彻底清除全部资料。NVMe 用硬盘自带的格式化，其他盘整盘写零。
    系统盘和 smartDisk 所在的盘不能擦。要勾选确认、输入序列号、等 5 秒倒数，最后再确认一次才会开始。

0.10.0  2026-11-25
  - USB 硬盘盒 / 外接盒也能读 SMART：SATA 硬盘盒（JMicron、ASMedia、Realtek、VIA 等大部分芯片），
    以及 ASMedia（ASM2362/2364）和 Realtek（RTL9210/9211）芯片的 NVMe 外接盒。会显示里面硬盘的真实型号和序列号。
  - JMicron NVMe 外接盒（JMS583）暂时还不支持。

0.9.0  2026-11-25
  - 健康记录：每次检测和托盘监控都会记下健康度、温度、坏道数，画成曲线，看得出硬盘是慢慢变差还是突然坏。
  - SMART 自检：硬盘自己做短测（约 2 分钟）或长测，结果和失败位置会显示出来，也写进报告。
  - 收购评级：按通电时间、写入量、健康度、坏道和自检结果自动给 A / B / C / D 级和建议。
  - 翻新盘识别：通电时间很少、但开关机次数、写入量或磨损很多的盘，会提示可能被清过 SMART。
  - 检测报告加二维码：手机扫一下就看到店名、日期、单号、每块硬盘的型号、序列号、健康度和评级（不用上网）。

0.8.3  2026-11-25
  - 测速完全照 CrystalDiskMark 8 的做法：每项先预热一次，再测 3 次取最好成绩；先测完全部读取再测写入；
    参数改成和 CrystalDiskMark 一样（之前多了「直写」设定，写入速度会偏低）。测速时间约 3 分半钟。

0.8.2  2026-11-25
  - 修正测速：顺序 Q8 和随机 Q32 测试之前会失败（DiskSpd 编译时漏了关闭调试检查），现在 8 项都能测。

0.8.1  2026-11-25
  - 测速某一项失败时会自动再试一次；仍然失败就显示「失败」（之前会显示 0.00），鼠标指着可看原因。
  - 每次测速的详细记录存在 C:\ProgramData\smartDisk\bench-log.txt，方便排查问题。

0.8.0  2026-11-24
  - 测速改用 Microsoft DiskSpd（和 CrystalDiskMark 同一个测速引擎），参数照 CrystalDiskMark 默认设置：
    1 GB 随机资料测试文件、每项 5 秒、每项之间休息 5 秒、不经过 Windows 缓存。结果应该和 CrystalDiskMark 很接近。
  - 测速多了「顺序 1M Q1」一行（和 CrystalDiskMark 一样共 4 行），报告也会写上。测速时间约 1 分半钟。

0.7.1  2026-11-24
  - 测速更准：测试文件改成整段不重复的随机资料（之前重复同一段资料，有些 SSD 会因此测得偏高），
    每项测试之间休息 5 秒（和 CrystalDiskMark 一样）。测速时间约 1 分钟。

0.7.0  2026-11-24

    中文模式的报告仍然是中英对照；English 模式的报告只有英文。

0.6.1  2026-11-24

    同行使用时改成自己的店名和号码就可以。

  - 报告窗口不再重复显示店铺信息栏（统一在「设置」修改）。

0.6.0  2026-11-24
  - 后台硬盘监控（给客户电脑用）：开机后在右下角托盘运行，每 15 分钟检查一次。
    第一次检测时记下每块硬盘的健康度作为基准（例如 100%）。之后健康度下降 2% 以上（例如降到 98%）、
    出现新坏道（重映射、待映射、无法修正扇区或 NVMe 介质错误增加）、或温度过高，就弹出提醒，
    请客户先备份资料，按钮可以直接用 WhatsApp 联系 PLANET。提醒只给客户看，不会发送任何资料出去。
  - SSD 正常磨损也一样，每下降 2% 提醒一次。
  - 托盘菜单：打开 smartDisk、立即检查、WhatsApp 联系 PLANET、以目前状态为基准（换硬盘或维修后用）、退出监控。
  - 新版本在后台下载，关机或重启时自动安装。
  - 硬盘页面显示监控基准（安装时的健康度和日期）。

0.5.0  2026-11-24
  - 硬盘测速：在硬盘上写一个 1 GB 临时文件，测顺序读写和 4K 随机读写（MB/s），约 40 秒，测完自动删除。
  - 坏道扫描：逐个扇区读取整块硬盘（只读，不改动资料），用方格图显示正常、慢、很慢和坏道的位置，可以随时停止。
  - 测速和坏道扫描的结果会写进 PDF 报告；扫到坏道时报告结论会变成「危险」。

0.4.0  2026-11-24
  - 新增「本机信息」页：电脑型号、Windows 版本和激活状态、CPU、内存（每条型号和频率）、显卡、主板和 BIOS、笔记本电池损耗。
  - 接口速度检查：SATA 显示 1.5 / 3 / 6 Gb/s，NVMe 显示 PCIe 代数和通道数（例如 PCIe 4.0 x4）。
    速度比硬盘支持的低时会提醒（例如 SATA 线有问题，或 M.2 插在共享通道）。
  - 固件问题提醒：三星 980 PRO / 990 PRO、西数 SN770、Crucial M4、希捷 7200.11 等已知有问题的固件会红字提醒更新。
  - 显示硬盘类型：SSD 或机械硬盘转速。
  - PDF 报告改为「电脑检测报告」，加入整机信息、接口速度、类型和固件提醒。
