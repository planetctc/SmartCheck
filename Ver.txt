smartDisk 版本记录 / Version history
（最新的在最上面 / newest first）

0.13.0  2026-11-25
  - 跟 smartAcc 连接：生成检测报告时可以勾选「同时存进 smartAcc」，报告 PDF 会按硬盘序列号自动存进
    smartAcc 里对应的维修单、收购单和发票附件。smartAcc 在同一台电脑上就能直接用；
    连另一台电脑上的 smartAcc 需要授权码。smartAcc 有登入账号的话，在设置 →「smartAcc 连接」填用户名和密码（密码加密保存）。
    需要 smartAcc 1.6.21 或以上。

0.12.0  2026-11-25
  - 远程通知（PLANET 专用，要授权码）：设置 →「远程服务（授权）」贴上授权码后，这台电脑会把硬盘状况传到店家的后台，
    硬盘变差、出现坏道或过热时店家会收到通知，后台网页也能看到每台客户电脑的硬盘状况。
    没有授权码就不会上传任何资料，客户还是只在自己电脑上看到提醒。

0.11.0  2026-11-25
  - 容量真假检测：把 U 盘 / 硬盘的空余空间全部写满再读回来核对，查出扩容的假容量盘。不会动原有文件，测完自动删掉测试文件。
  - 安全擦除：卖盘或送人前彻底清除全部资料。NVMe 用硬盘自带的格式化，其他盘整盘写零。
    系统盘和 smartDisk 所在的盘不能擦。要勾选确认、输入序列号、等 5 秒倒数，最后再确认一次才会开始。

0.10.0  2026-11-25
  - USB 硬盘盒 / 外接盒也能读 SMART：SATA 硬盘盒（JMicron、ASMedia、Realtek、VIA 等大部分芯片），
    以及 ASMedia（ASM2362/2364）和 Realtek（RTL9210/9211）芯片的 NVMe 外接盒。会显示里面硬盘的真实型号和序列号。
  - JMicron NVMe 外接盒（JMS583）暂时还不支持。

0.9.0  2026-11-25
  - 健康记录：每次检测和托盘监控都会记下健康度、温度、坏道数，画成曲线，看得出硬盘是慢慢变差还是突然坏。
  - SMART 自检：硬盘自己做短测（约 2 分钟）或长测，结果和失败位置会显示出来，也写进报告。
  - 收购评级：按通电时间、写入量、健康度、坏道和自检结果自动给 A / B / C / D 级和建议。
  - 翻新盘识别：通电时间很少、但开关机次数、写入量或磨损很多的盘，会提示可能被清过 SMART。
  - 检测报告加二维码：手机扫一下就看到店名、日期、单号、每块硬盘的型号、序列号、健康度和评级（不用上网）。

0.8.3  2026-11-25
  - 测速完全照 CrystalDiskMark 8 的做法：每项先预热一次，再测 3 次取最好成绩；先测完全部读取再测写入；
    参数改成和 CrystalDiskMark 一样（之前多了「直写」设定，写入速度会偏低）。测速时间约 3 分半钟。

0.8.2  2026-11-25
  - 修正测速：顺序 Q8 和随机 Q32 测试之前会失败（DiskSpd 编译时漏了关闭调试检查），现在 8 项都能测。

0.8.1  2026-11-25
  - 测速某一项失败时会自动再试一次；仍然失败就显示「失败」（之前会显示 0.00），鼠标指着可看原因。
  - 每次测速的详细记录存在 C:\ProgramData\smartDisk\bench-log.txt，方便排查问题。

0.8.0  2026-11-24
  - 测速改用 Microsoft DiskSpd（和 CrystalDiskMark 同一个测速引擎），参数照 CrystalDiskMark 默认设置：
    1 GB 随机资料测试文件、每项 5 秒、每项之间休息 5 秒、不经过 Windows 缓存。结果应该和 CrystalDiskMark 很接近。
  - 测速多了「顺序 1M Q1」一行（和 CrystalDiskMark 一样共 4 行），报告也会写上。测速时间约 1 分半钟。

0.7.1  2026-11-24
  - 测速更准：测试文件改成整段不重复的随机资料（之前重复同一段资料，有些 SSD 会因此测得偏高），
    每项测试之间休息 5 秒（和 CrystalDiskMark 一样）。测速时间约 1 分钟。

0.7.0  2026-11-24
  - 加入英文：「设置」里可以选 中文 / English。界面、客户提醒窗口、托盘菜单和 PDF 报告都会跟着换。
    中文模式的报告仍然是中英对照；English 模式的报告只有英文。

0.6.1  2026-11-24
  - 新增「设置」（左下角）：店名、地址、联系方式，以及客户提醒里的 WhatsApp 按钮——可以填自己的号码，也可以关掉不显示。
    同行使用时改成自己的店名和号码就可以。
  - 提醒窗口的按钮改为「WhatsApp 联系我们」，信息开头用设置里的店名。
  - 设置改存到 ProgramData，后台监控在任何 Windows 用户下都读得到。
  - 报告窗口不再重复显示店铺信息栏（统一在「设置」修改）。

0.6.0  2026-11-24
  - 后台硬盘监控（给客户电脑用）：开机后在右下角托盘运行，每 15 分钟检查一次。
    第一次检测时记下每块硬盘的健康度作为基准（例如 100%）。之后健康度下降 2% 以上（例如降到 98%）、
    出现新坏道（重映射、待映射、无法修正扇区或 NVMe 介质错误增加）、或温度过高，就弹出提醒，
    请客户先备份资料，按钮可以直接用 WhatsApp 联系 PLANET。提醒只给客户看，不会发送任何资料出去。
  - SSD 正常磨损也一样，每下降 2% 提醒一次。
  - 托盘菜单：打开 smartDisk、立即检查、WhatsApp 联系 PLANET、以目前状态为基准（换硬盘或维修后用）、退出监控。
  - 新版本在后台下载，关机或重启时自动安装。
  - 硬盘页面显示监控基准（安装时的健康度和日期）。

0.5.0  2026-11-24
  - 硬盘测速：在硬盘上写一个 1 GB 临时文件，测顺序读写和 4K 随机读写（MB/s），约 40 秒，测完自动删除。
  - 坏道扫描：逐个扇区读取整块硬盘（只读，不改动资料），用方格图显示正常、慢、很慢和坏道的位置，可以随时停止。
  - 测速和坏道扫描的结果会写进 PDF 报告；扫到坏道时报告结论会变成「危险」。

0.4.0  2026-11-24
  - 新增「本机信息」页：电脑型号、Windows 版本和激活状态、CPU、内存（每条型号和频率）、显卡、主板和 BIOS、笔记本电池损耗。
  - 接口速度检查：SATA 显示 1.5 / 3 / 6 Gb/s，NVMe 显示 PCIe 代数和通道数（例如 PCIe 4.0 x4）。
    速度比硬盘支持的低时会提醒（例如 SATA 线有问题，或 M.2 插在共享通道）。
  - 固件问题提醒：三星 980 PRO / 990 PRO、西数 SN770、Crucial M4、希捷 7200.11 等已知有问题的固件会红字提醒更新。
  - 显示硬盘类型：SSD 或机械硬盘转速。
  - PDF 报告改为「电脑检测报告」，加入整机信息、接口速度、类型和固件提醒。

0.3.2  2026-11-24
  - 温度原始值改为正确显示（例如「43 °C（最低 27 / 最高 58）」），不再显示一长串数字。
  - 补齐东芝、希捷、西数和 SSD 常见属性的中文名称，减少「厂商自定义」。
  - 硬盘列表、标题和检测报告显示盘符（C: / D:）。
  - NVMe 固态硬盘显示真正的序列号（之前显示的是一串 ID 编号）。

0.3.1  2026-11-24
  - 联系电邮改为 planet@planetctc.com.my（关于窗口和检测报告）。

0.3.0  2026-11-24
  - 网上自动更新：打开程序后会检查新版本，有的话问你要不要下载安装，下载好后重启就完成。
    「关于」窗口里也有「检查更新」。（这个版本要手动装一次，以后就会自动更新。）
  - PDF 检测报告：填客户名称、单号、检测人员和备注，一键生成 A4 报告，
    包含店铺信息、整体结论、每块硬盘的健康度和重点数据，以及签名栏。店铺信息可以在报告窗口里修改。
